# 统一下载管理

Yachiyo Claw Android 将软件更新、本地模型、Linux 环境、插件、Skills、远程主题和应用资源的实际包体
下载汇总到 **设置 > 下载管理**。目录查询、市场搜索和元数据读取仍由各功能自己的 API 完成；确认下载后
的文件传输才进入统一下载器。

## 使用方法

下载任务开始后，可以离开来源页面或关闭进度弹窗。下载管理会显示任务类型、状态、已下载/总大小、
速度、预计剩余时间、百分比和失败原因，并提供暂停、继续、取消和移除记录操作。点击 Android 下载通知
会直接打开下载管理。

每个活动任务使用一条独立的前台通知。清除通知不会取消任务；手动暂停、取消、Android 强制停止应用、
系统网络限制或存储不足会影响执行。WorkManager 会保存排队状态和分段文件，应用进程被回收或设备重启后
会按 Android 调度规则继续。用户在系统设置中“强制停止”应用后，Android 会阻止后台工作，直到再次启动
应用。

完成记录可以从列表移除。移除本地模型下载记录不会删除已经安装的模型；模型文件应在本地模型页管理。
取消任务会丢弃对应的未完成包体。插件、Skill 和主题在校验并消费包体后可以保留完成记录，但临时下载
文件会被释放。

## 下载器设置

点击下载管理右上角的设置按钮可以配置：

- **HTTP 代理服务器：** 支持 `http://host:port` 或 `https://host:port`，不接受 URL 中的账号密码、路径、
  查询参数或片段。留空表示使用系统网络。
- **并发线程数：** 每个支持 Range 的大文件默认使用 8 个分段，范围为 1-64。服务器不支持范围请求时
  自动回退到单流下载。应用还有全局连接上限，多个任务不会各自无限占用连接。
- **失败重试次数：** 默认 3，范围为 0-16。
- **仅在 Wi-Fi 下下载：** 使用 Android 的非计量网络约束；修改后会重新调度活动任务。

下载器同时要求设备网络可用且存储空间不处于系统“低”状态。代理设置只用于应用下载器，不会自动修改
LLM Provider、MCP、插件运行时或 Linux 环境内程序的网络配置。

## 完整性与网络边界

- 软件更新必须来自本项目允许的 GitHub Release 路径，并具有 GitHub asset SHA-256 或匹配的
  `.sha256` 文件；下载后还会验证包名和签名链。
- 模型、插件和 Skill 在来源提供摘要时进行 SHA-256 校验；插件市场包还验证受信任发布者签名。
- 通用下载只接受公开 HTTPS 地址，限制重定向和最大体积，并拒绝回环、链路本地和私网目标。
- 断点续传会校验远端响应与分段长度。摘要不匹配的分段会丢弃并重新下载，不会发布为完成文件。

下载成功不代表第三方内容可信或许可证允许使用。安装或运行模型、Skill、插件前仍应核对来源、权限和
许可证。

## 故障排查

1. 打开下载管理查看稳定错误码的中文说明，不要只依赖已经被清除的通知。
2. 检查剩余空间、Wi-Fi 限制和代理地址；局域网代理在 Android 模拟器/真机中不能总是使用宿主机的
   `127.0.0.1`。
3. 对失败任务先点“继续”。服务器文件已变化、摘要错误或不支持可靠续传时，取消后重新创建任务。
4. 若系统强制停止过应用，先重新打开 Yachiyo Claw；若仍无调度，检查厂商后台限制和电池优化设置。

开发者可通过 `YachiyoDownloads` 原生接口接入有限、可恢复的应用资源下载。业务模块仍负责定义允许的
来源、体积、摘要与安装事务，不能把模型输出的任意 URL 直接交给下载器。
