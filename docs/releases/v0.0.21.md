# Yachiyo Claw v0.0.21 — 预览版

交互式页面重新排版，恢复可正常显示的内置 Live2D 模型，统一苹果风格的圆弧 R 角。

## 本次更新

- 顶部仅保留会话记录、角色切换和设置；聊天/Agent、文字、语音、发送/停止集中在底部输入区。
- 模型、人格、声音、摄像头和角色位置改为分组设置，面板提供明确的关闭按钮。
- 角色避开工具栏和输入区；回复可以收起，不再自动消失；输入和设置时暂停角色动画，减轻交互负担。
- 圆形图标按钮、胶囊底栏、统一 R 角卡片和悬浮面板；修复旧 WebView 选择器失效和重复边距。
- 修复 Android 全屏键盘遮挡、横竖屏安全区域更新竞态，以及 WebView 83 的 Live2D DOM API 崩溃。
- 恢复损坏的内置 MOC，保护二进制文件免受换行转换；恢复与 Pixi 适配器配套的 Cubism Core 5.0 运行时。
- 补充 x86_64 PRoot 兼容代码、Ubuntu 硬链接解压处理、缓存依赖恢复和可复现的原生构建脚本。

## 验证范围与限制

- TypeScript、lint、Web 构建和 Android 构建已执行；全量测试 2029 通过，54 个外部条件用例跳过。
- Android 原生测试 126 项：124 通过，2 项因 Windows 符号链接权限跳过。
- Android 11 / WebView 83、Android 13 / WebView 109、Android 15 / WebView 124 已进行界面和模型烟测；Android 11 使用修复后的渲染预览。Android 15 另检查了明暗主题、1440×3200 和横屏。
- **这不是“所有验收通过”的正式版。** 最新候选 APK 的安装命令被自动审批拦截，最终安装回归未完成。
- 本地网关的临时入口失效；重新发现入口的操作被自动审批拦截，真实 API 俄罗斯方块 Agent 全流程未完成。
- Alpine 的子进程、Node/Git 已在模拟器运行；Ubuntu 解压已验证，但工具链安装遇到旧 rename 调用失败。最终 ENOSYS 回退补丁已编译，尚未完成设备验证。
- 复杂 Live2D 模型的动画在本次 Android 15 模拟器上仍约 10 帧；暂停角色后的输入界面约 60 帧。未据此宣称实体手机性能已验证。
