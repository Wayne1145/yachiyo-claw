# Yachiyo Claw v0.0.25 — Realtime 通话与交互体验

版本号 `0.0.25`，Android versionCode `25`。`0.0.24` 仅为本地测试构建，未公开发布。本版沿用 NewDreamStudio 证书和包名，提供 arm64-v8a / x86_64 通用 APK。

## 新增与修复

- 交互式页面提供“聊天 / Agent / 实时”三段切换。实时模式隐藏打字区、普通聊天模型和推理强度，只使用独立 Realtime 配置。
- 原生 WSS 音频支持 OpenAI Realtime GA / DashScope；加入开始/结束通话、关麦、播放静音、可选摄像头帧、音量表和 VAD 阈值调节。
- 修正千问默认配置为已实测的 `qwen3.8-omni-flash-realtime`、`Tina`。仅修正官方地址上的已知旧模板，保留自定义网关和其他显式配置。服务端具体错误不再被通用连接失败覆盖。
- 实时模式自动准备内部工具任务，可调用工作区、沙箱、搜索、记忆等已启用工具，沿用 Broker 审批和审计，不自动开启手机控制。真实验收完成了 function call → 审批 → 沙箱退出码 0 → 回传 → 模型续答。
- 修复交互式摄像头工具注册时序和权限撤销检查；高画质 Live2D 新增原生像素与超采样档，显示实际渲染尺寸。
- 新增用量统计及可选 sub2api 倍率/余额适配；仅统计实际报告的数据，未知值不伪装为零。
- Agent DOM 浏览器改为离屏运行，显式预览才打开带导航控件的页面；修复等待结果判定。
- 修复关于页版本显示受远程检查阻塞、交互式横屏布局，以及模拟器 ARM 翻译环境下的沙箱 ABI 状态误报。

## 使用提示与边界

在设置中选择 Realtime 协议并填写相应平台的 Key，再到交互式页面切换“实时”。普通聊天的 Key/模型不自动替代 Realtime 配置。摄像头上传需要每次通话确认；离开页面或进入后台会结束通话。

千问短音频输出和一次真实内部命令调用已验证；真实麦克风识别、持续视频、全部上游模型与所有工具组合尚未全面验收。sub2api 真实余额接口仍待部署端验证。旧 Android 11 WebView 83 / 软件 GPU 的 Live2D 测试未通过；更高渲染像素也不能增加源纹理细节。离屏 WebView 不等同于桌面 Chromium。

完整范围见 [验收记录](v0.0.25-validation.md)。项目仍为早期预览，请保留数据备份，不把测试覆盖等同于绝无缺陷。
