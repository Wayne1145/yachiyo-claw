# Yachiyo Claw v0.0.23 — Agent 连续对话与模型兼容修复

本次修复长对话中“继续”后助手回复消失、DeepSeek 检查通过但 Agent 报 400，以及沙箱命令正常完成却被误报失败的问题。

- 修复后台 token 统计用旧消息列表覆盖新回复的竞态，消息补丁在数据库写事务中更新，保留流式内容与执行状态。
- DeepSeek（包括自定义 OpenAI 兼容配置）使用兼容的工具选择参数，并保留多轮工具调用所需的思考内容。
- Agent 与普通聊天共用消息和输入组件，切换能力时保持布局一致；正确显示模型名称、提供商错误详情，并清除失败后的重试标记。
- 修复 Alpine/Ubuntu 进程正常退出时被误判为 `sandbox_process_disappeared / 126`；加强跨进程运行库初始化和取消时的子进程清理。
- 插件页面的语言切换不再取消执行中的动作，避免点击时状态尚未同步而丢失操作。
- 合并 v0.0.22 设置页改进并保留本地模型流式输出、主题同步与去除上游商业服务入口等已有修复。

版本号 `0.0.23`，Android versionCode `23`。使用原 NewDreamStudio 证书，包名不变，可覆盖升级。APK 同时包含 arm64-v8a 与 x86_64。

验证详情和限制见 [验收记录](v0.0.23-validation.md)。本地小模型和 MuMu 的结果不代表所有 4B/7B 模型、手机 GPU/NPU 或所有系统权限后端均已通过测试。
