# Yachiyo Claw v0.0.26 — 首次配置与动态模型列表修复

版本 `0.0.26`，Android versionCode `26`。沿用 NewDreamStudio 签名与包名，支持从 v0.0.25 覆盖升级，APK 包含 arm64-v8a 和 x86_64。

- 主页填写 API Key 后直接加密保存，仅检查非空，不再要求先连接服务或测试聊天模型。
- 移除内置 `gpt-5.6` 模型目录与新会话的固定模型 ID。启动或 Key 变化后，独立从 Yachiyo API `/v1/models` 获取列表。
- 保留仍有效的默认模型；旧模型不在列表中时选择当前返回的聊天模型，不把 embedding/image 模型当作默认聊天模型。
- 网络异常或模型列表为空不撤销已经保存的 Key；网络异常保留已有缓存，可在 Yachiyo API 设置中手动刷新。
- 更新模型列表时保留同 ID 的协议选择；不抢占其他提供商的默认模型，也不自动修改已有非空对话。空白会话可以修正失效模型。
- 尚未发现可用模型时不启动无界面定时推理，避免向上游发送空模型 ID。

已验证新用户断网保存、模拟服务返回新模型后的自动选择和重启持久化。未执行付费聊天测试；实时模型供应情况仍以服务端返回和账户权限为准。其他功能和既有兼容性、安全限制继承 v0.0.25，本次不宣称解决全部依赖安全告警。

详情见 [验收记录](v0.0.26-validation.md)。
