# Yachiyo Claw v0.0.14

`v0.0.14` 集中修复应用内更新、本地模型预加载、移动端国际化与液态玻璃界面问题。

## 主要变化

### 应用内更新与下载镜像

- 更新器会比较已安装 APK 与下载包的 `versionCode`，拒绝同版本和降级安装，并清理已经失效的已验证安装包与完成状态。
- 下载设置新增 GitHub 与 Hugging Face 镜像开关，分别用于应用更新资源和模型目录/权重下载。
- 首次成功启动时通过 Cloudflare trace 仅检测国家或地区；位于中国大陆时默认启用两个镜像。检测失败不会阻塞启动，用户手动选择后也不会再被自动设置覆盖。
- 镜像地址仍受来源与路径白名单约束，更新 APK 继续执行 SHA-256 与签名校验。

### 本地 GGUF 模型

- “加载到内存”会关闭 llama.cpp 的内存映射并真正预读模型；普通直接推理保留内存映射，以兼顾启动速度和内存占用。
- 已经以内存映射方式加载的模型可以升级为完整预加载，无需先手动卸载。
- 预加载前会校验模型体积和运行时余量；完成后展示模型字节数、进程 PSS、加载方式与实际耗时，避免仅凭按钮状态误判加载成功。

### 语言与错误说明

- 更新、下载、语音、角色、用户画像/记忆、Linux 环境和插件运行页接入统一国际化资源。
- API 状态码、密钥/余额、限流、上下文超限、TLS 以及本地模型内存、进程、模板和文件错误均提供应用内解释。
- 移除 Chatbox FAQ、授权和免费试用等遗留外链；错误信息不再把用户带到无关的 Chatbox 页面。
- 软件语言继续由“通用设置”中的唯一语言选项控制，没有增加重复入口。

### 液态玻璃主题

- 聊天顶部的头像、标题、搜索、更多、历史与状态保持可见，仅 Agent 扩展控制可收起。
- 推理强度、附件、MCP/知识库和网络工具收纳到仅液态玻璃主题启用的横向二级托盘，避免窄屏挤出视口。
- 设置列表、状态面板、模型行、主题卡、菜单、弹窗、输入框和常用控件统一半透明高光、阴影、模糊与饱和度效果。
- 不支持 `backdrop-filter` 的 Android System WebView 使用高不透明度回退，保证内容清晰可读。
- 修复短横屏下聊天输入框被底部导航遮挡的问题；输入区会压缩为单行起始高度并隐藏非必要欢迎内容。

### 源码构建

- 构建文档明确区分 Capacitor 原生桥接与运行时 ZIP/Web Worker 插件；Gradle/Android Studio 会在打包前自动同步 Web Bundle，第三方插件不会作为 Gradle 模块出现。
- 说明 `USE_FINGERPRINT` 弃用提示来自对 `androidx.biometric` 传递权限的清单删除规则，最终 APK 不包含指纹或生物识别权限。

## 隐私与兼容性

- 地区检测只用于首次镜像默认值，详见 [PRIVACY.md](../../PRIVACY.md)。启用第三方镜像时，相应镜像运营方会处理下载请求。
- GGUF 完整预加载会显著增加物理内存占用；模型能否运行仍取决于量化、上下文长度、设备可用内存和 SoC。
- 使用与已安装版本相同签名的 `v0.0.14` APK 覆盖安装，才能保留会话、Provider、插件、模型和应用私有文件。不要先卸载旧版本。

发布构建需通过 [AGENTS.md](../../AGENTS.md) 中的 Android 门禁、全量测试、Web 构建、签名校验和模拟器点击检查。
