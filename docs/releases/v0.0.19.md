# Yachiyo Claw v0.0.19

This release adds a native headless Agent runtime for scheduled tasks, an official plugin store, and the first signed Ubuntu 24.04 development-environment plugin.

## Highlights

- Scheduled OpenAI-compatible Agent tasks can run through WorkManager without an Activity or WebView. Provider credentials and runtime configuration are encrypted with Android Keystore, while checkpoints, leases, bounded tools, and audit records survive normal process death.
- Tasks that need phone UI, user approval, camera, credentials, or other foreground-only capabilities pause and hand off to the existing foreground Agent flow.
- The official plugin store loads automatically, supports search, uses the configured GitHub mirror with origin and bundled-catalog fallback, and keeps developer sideload sources under an advanced section.
- The signed Ubuntu 24.04 plugin installs Canonical Ubuntu Base 24.04.4 for arm64 or amd64 through the unified persistent downloader, verifies its pinned SHA-256, extracts atomically, and provides Python, Node.js, Git, build, file, and background-job tools.
- Installed plugin tool descriptions are included in the Agent prompt. Android app discovery and permission status are available in the initial phone-control tool stage.

## Android limitation

Android deliberately prevents WorkManager, alarms, and receivers from running after the user presses **Force stop**. Normal background process death, system reclaim, reboot, package replacement, and Activity/WebView destruction remain recoverable.
