# Yachiyo Claw v0.0.11

`v0.0.11` 集中补全 Android 的统一下载、Feature 架构、主题和 Skills，并修复这些能力离开页面或
应用进程重建后的事务恢复。它仍是面向备用机和模拟器的早期预览版本。

## 主要变化

### 统一下载管理

- 软件更新、本地模型、Linux 环境、插件、Skills、远程主题和应用资源包体统一显示在
  **设置 > 下载管理**。
- 原生 WorkManager 下载支持分段并发、断点续传、暂停/继续/取消、失败重试、速度/ETA、独立常驻通知
  和进程重建后的自动恢复。
- 下载器设置支持 HTTP(S) 代理、1-64 线程（默认 8）、0-16 次重试和仅 Wi-Fi；不支持 Range 的服务器
  自动回退到单流。
- 通知点击可把已在前台的应用直接导航到下载管理；清除通知不会取消任务。

### 第三方插件开发者预览

- manifest、包校验、签名市场、安装事务、权限模型、声明式 UI 和 Host API 已进入源码。
- 插件使用严格 manifest、逐文件 SHA-256、不可变版本目录、原子更新、失败回退、历史版本回滚、健康
  熔断、活动审计和完整卸载。
- 插件导航/设置贡献按启用状态、UI grant、`minAppVersion` 和健康状态统一门控。
- 插件下载和用户同意事务可在应用进程重建后恢复；用户主动删除下载不会自动重建任务。
- Android 入口在本版本默认隐藏。目标 System WebView 中 opaque sandbox iframe 能运行引导脚本，但
  其中的 Blob Worker 无法可靠启动并会触发 `load_timeout`，因此本版不把插件运行时作为可用功能发布。

### 主题和 Skills

- 新增声明式主题中心：粘贴 JSON、选择文件或公开 HTTPS 导入，临时预览、安装、切换和删除。主题只
  能覆盖已知颜色 token，不能加载脚本或任意 CSS。
- 远程主题下载完成后可在重启时恢复到预览流程。
- Skills 页直接展示热门/搜索内容，并支持 GitHub、`skills.sh` 和 SkillHub 固定 revision 安装。
- GitHub/SkillHub 包体进入统一下载管理，安装事务可恢复；更新检查读取真实远程 commit/revision。
- shell、Python 和 JavaScript Skill 入口在执行前校验哈希，并通过 Tool Broker 审批后进入应用私有
  PRoot 环境。

### Feature 架构与安全

- 内置能力迁移到类型化 Feature manifest、依赖解析、设置、UI、提示词、工具和生命周期注册表。
- 原生桥按启用模块自检；一个模块初始化或清理失败不会绕过其他模块的清理和门控。
- 插件授权和 KV 数据使用 Android Keystore 支持的上下文绑定加密，并迁移旧明文/旧 envelope。
- 插件网络代理限制公开 HTTPS 域名、每次重定向、DNS 解析、请求/响应大小和取消信号。

### 修复

- 修复插件安装权限复选框连续选择时因 React 合成事件失效导致的崩溃。
- 修复权限向导“稍后处理”后立即再次弹出。
- 修复设置到任务的首次导航、下载通知前台路由、Linux 安装状态和离页轮询。
- 移除 Android 上无意义的“打开 Skills 文件夹”入口，并改进下载/插件错误的中文说明。

## 重要边界

- PRoot 不是内核容器。获准执行的 Skill Linux 命令可能修改共享 rootfs 并自行联网。
- 第三方插件运行时未在 Android `v0.0.11` 开放；相关源码仅用于后续开发和安全审计。
- Skill 更新检查目前只报告新 revision，不会静默安装；用户需确认来源后重新安装。
- 统一下载器不会让任意 URL 自动可信。各模块仍负责来源、体积、摘要、签名和安装策略。
- GGUF 仍以 CPU 文本推理为主，真实 1B-4B 模型的速度、内存、温升和多 SoC 稳定性尚未形成完整矩阵。
- WorkManager 可以恢复下载和任务检查点，但 Android 的“强制停止”会阻止后台调度直到用户重新打开应用。

## 升级说明

使用与已安装版本相同签名的 `v0.0.11` APK 覆盖安装，才能保留会话、Provider、模型和应用私有文件。
不要卸载旧版本后再安装，也不要使用 `adb install` 而不带 `-r`。应用内更新只接受项目 GitHub Release
路径、SHA-256 可验证且包名/签名链匹配的 APK。

## 发布门禁

发布构建必须按 [AGENTS.md](../../AGENTS.md) 运行 TypeScript、Android foundation、原生日志、Capacitor
同步、Gradle 单测和 APK 构建；本版本还需要全量 `pnpm test`、`pnpm build:web` 和：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/yachiyo-env.ps1 pnpm verify:android-update-release -- `
  --apk .cache/release/v0.0.11/yachiyo-claw-v0.0.11.apk `
  --previous-apk .cache/release/v0.0.10/yachiyo-claw-v0.0.10.apk
```

Android 11、13、15/16 的同签名升级和关键功能 smoke test 完成后，才可把 Release 从 draft
设为公开。下载器、主题、Skills 和插件开发资料分别见 [downloads.md](../downloads.md)、
[themes.md](../themes.md)、[skills.md](../skills.md) 和 [插件用户指南](../plugins/user-guide.md)。
