# Yachiyo Claw v0.0.22 — 设置页重构

设置页面统一为与应用一致的玻璃材质、圆弧 R 角和分组布局，常用选项更容易找到，手机上的表单和底部导航更易操作。

## 本次更新

- 重构设置导航与搜索，按用途分组；打开搜索结果再返回时保留搜索状态。
- 统一外观、通用、聊天、模型服务、语音、角色、记忆、扩展和开发者设置的页面结构。
- 卡片、表单、按钮和确认面板采用统一 R 角；优化明暗主题、窄屏、横屏和键盘弹出时的布局。
- 修复旧版 WebView 中导航标题堆积、按钮边距和底栏黑边；避免历史页面重复挂载。
- 字号拖动先预览，释放后保存；语音凭据加载完成后再允许编辑，加载失败可重试。
- 统一功能依赖、MCP 删除和记忆清除的确认交互，取消或离开页面不会执行操作。

## 版本与安装

- 应用版本：`0.0.22`；Android versionCode：`22`。
- 安装文件：`app-release.apk`；校验文件：`app-release.apk.sha256`。
- 使用原有 NewDreamStudio 发布证书签名，支持从 `0.0.21` 覆盖升级。
- 本次为正式 Release 构建，关闭 Android 调试标记，包含 `arm64-v8a` 和 `x86_64`。
- 提供与发布标签对应的完整源码 `yachiyo-claw-v0.0.22-source.zip` 及校验文件。

## 验证范围

- 全量 Vitest：2040 通过，54 项需要外部条件的用例跳过。
- TypeScript、lint、原生日志隐私检查和 Web 生产构建通过。
- 设置页代码已在 Android 11 / WebView 83、Android 13 / WebView 109 和 Android 15 / WebView 124 模拟器验收，覆盖 19 个设置路由。
- 另检查了明暗主题、1440×3200、横屏、窄屏、键盘遮挡、搜索返回和确认取消。详见 [设置页验证记录](../settings-validation.md)。
