# v0.0.21 preview validation — 2026-10-01

This record distinguishes source checks, renderer previews, installed debug APKs,
and the final signed candidate. It is not a claim that the full acceptance request passed.

## Source and host checks

- Full Vitest: 271 files passed, 2 skipped; 2029 tests passed, 54 skipped.
- TypeScript passed. Biome lint has no errors; existing warnings remain.
- Web production build and Capacitor Android renderer synchronization passed.
- Android native log privacy gate passed (117 source files).
- Native tests: 126 tests, 0 failures/errors, 2 skipped on Windows because the host
  cannot create the required test symlinks. Archive hardlink byte-budget tests passed.
- Debug and signed Release builds have succeeded. Final artifact hashes and audit
  results are recorded with the release assets after packaging.

## Device observations

- API 35 / WebView 124: recovered MOC creates a model with 409 drawables, and ADB
  screenshots show the character. CDP screenshots alone can omit the WebGL layer.
- Light and dark portrait, 1440x3200 portrait, and landscape checks found consistent
  corner radii, usable touch targets, no horizontal overflow and no overlap between
  the measured character stage and toolbar/composer.
- API 30 / WebView 83: an installed debug build exposed unsupported
  `Element.replaceChildren`. The corrected renderer preview loaded the model and
  passed portrait/landscape geometry checks. A subsequent source change replaces
  `:has()` with an explicit shell class to avoid duplicate safe-area padding.
- API 33 / WebView 109: installed debug build loaded the model and passed portrait
  and landscape geometry checks after loading completed.
- Native fullscreen keyboard resize was verified: the viewport shrank from about
  915 to 530 CSS pixels and the composer remained above the IME. A stale landscape
  inset was then found, fixed and covered by two asynchronous regression tests.
- Rendering the model on API 35 measured median frame time 100ms, p95 116.8ms;
  reducing blur/resolution did not improve it. With model animation paused during
  input, median/p95 were about 16.7ms. No physical-device frame-rate claim is made.
- Alpine installation completed through the app, Python spawned a child shell,
  and Node/Git returned exit code 0. Ubuntu rootfs extraction succeeded after
  materializing archive hardlinks as copies and fixing dangling-link cleanup.

## Outstanding verification

- The final APK installation command was rejected by automatic approval with only
  `blocked by policy`. It was not retried through another installation method.
- The final PRoot legacy-rename ENOSYS retry and automatic code-cache dependency
  recovery therefore remain unverified on the final installed package. An earlier
  runtime proved renameat and renameat2 work while legacy rename returns ENOSYS;
  the final patch reuses the existing PRoot renameat translation on that error.
- Ubuntu's complete developer toolchain and full Ubuntu/Alpine runtime separation
  regression are not marked passed.
- A real local-relay kimi-k3 request returned READY, but the temporary relay later
  refused connections. Automatic approval rejected process-based relay rediscovery
  and restarting its forwarder. The user was asked for a fixed test gateway.
  The real API Tetris Agent workflow remains incomplete.
- No entity-wide promise of zero Chromium startup tile warnings is made. Earlier
  blank-page control tests also emitted them; a full physical-device matrix remains
  outstanding.
- Previous update-installer validation from v0.0.20 is historical evidence, not a
  new end-to-end update test of this preview artifact.

Private signing material, relay configuration, device data, raw logs and generated
test tooling remain in ignored workspace directories and are not release assets.
