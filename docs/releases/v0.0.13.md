# Yachiyo Claw v0.0.13

`v0.0.13` 统一 Android 对话页的顶部与输入区，修复历史会话和本地模型列表问题，并增加第二套内置液态玻璃主题。

## 主要变化

### 对话界面

- Android 不再渲染 Chatbox 的第二条白色会话标题栏，聊天与 Agent 共用 Yachiyo Claw 顶栏。
- 搜索、更多和会话历史按钮固定横向排列；Android 更多菜单不再显示未使用的 Thread History。
- Agent 输入框下方不再重复显示内部工具模式、推理强度和上下文统计，相关控件保留在输入框内。
- Android 可视消息列表隐藏系统人格消息，但系统消息仍保留在模型上下文中。

### 会话历史

- 左滑操作增加重命名，并同步更新共享聊天与 Agent 任务名称。
- 修复当前会话未滑动时透出收藏、分叉和删除按钮的问题。
- 历史列表使用受限高度与独立纵向滚动，长列表不再重叠。

### 本地模型

- 搜索结果以有限并发补取文件清单，显示首选可运行 GGUF、完整 GGUF 分片组、LiteRT-LM 或 TFLite 文件的精确下载大小。
- 文件信息尚未返回时显示加载状态；无法形成可验证下载组时显示不可用，不再回退到仓库总大小。

### 液态玻璃主题

- 主题中心增加不可删除、不可被第三方包覆盖的 `Yachiyo Liquid Glass` 内置主题。
- 聊天背景为纯白，顶栏、底栏、输入框、菜单、常用按钮与输入控件使用半透明玻璃样式。
- 顶栏可通过箭头整体收起，收起后保留小型恢复按钮；减少动画系统设置会关闭该过渡。
- 不支持 `backdrop-filter` 的 Android System WebView 使用高不透明度回退，保证文字与控件可读。

## 升级说明

使用与已安装版本相同签名的 `v0.0.13` APK 覆盖安装，才能保留会话、Provider、插件、模型和应用私有文件。不要先卸载旧版本。

发布构建需通过 [AGENTS.md](../../AGENTS.md) 中的 Android 门禁、全量测试、Web 构建、签名校验和模拟器点击检查。
