# Yachiyo Claw v0.0.12

`v0.0.12` 重点完成 Android 插件运行时、本地模型可用性、模型生命周期同步和全局英文界面。
它仍是面向备用机与模拟器的早期预览版本。

## 主要变化

### Android 第三方插件

- 开放插件中心、HTTPS/本地 ZIP 安装、声明式页面、设置入口、Agent 工具、权限与活动记录。
- 插件脚本运行在 opaque-origin Worker 中，通过带版本的纯 JSON RPC 访问白名单 Host API，不继承应用
  WebView 的 IndexedDB、网络或 DOM 权限。
- 能力授权绑定插件入口摘要；安装包含逐文件摘要、事务恢复、不可变版本目录、失败回滚、健康熔断和完整
  卸载。
- 实机验证示例插件由 FunctionGemma 生成结构化工具调用，经原生最上层审批、隔离 Worker 执行、Tool
  Broker 回填，再由本地模型生成最终回答。

### 本地模型

- 修复 GGUF 和 LiteRT-LM 启动、聊天模板识别、工具能力声明及小模型提示词过长导致的空白回复。
- 已下载模型列表支持设为默认、加载进内存、卸载和删除，并显示运行时状态。
- 删除模型时同步移除重复原生记录与文件、Provider 条目、默认模型、收藏和辅助模型引用，模型选择器不再
  保留已删除项。
- 小于 1B 的聊天模型使用紧凑人格；具备工具能力的小模型按用户请求筛选最相关工具，完整 Tool Broker、
  审批和审计规则不变。
- Android 12、6 GB 模拟器已验证 Gemma 3 270M GGUF 连续两轮回复、FunctionGemma LiteRT-LM 工具
  调用和本地模型进程驻留。

### 界面与语言

- Yachiyo Claw 自定义的聊天、交互式、Agent、权限、工作区、下载、主题、插件和本地模型页面补全英文
  文案；切换语言不再只影响通用设置。
- 内置持久下载任务名称在展示时按当前语言翻译，模型名、角色名、任务名和第三方内容保持原文。
- 在 `1440x3200` 与 `1200x2608` 竖屏视口检查聊天工具栏、推理强度、Agent 控制、交互式顶栏、模型
  卡片和底部导航，没有发现遮挡或横向溢出。

### 修复与加固

- 修复首次启用 Agent 后选择工作区或快速开始时偶发“无法找到任务”的竞态。
- 插件运行时改用延迟释放 Worker Blob URL 的 opaque `data:` frame 传输，兼容当前 Android System
  WebView，同时保持环境能力删除和 CSP 限制。
- 加固插件网络重定向/DNS/大小限制、授权撤销、安装恢复、并发调用、取消信号和审计记录。
- 示例 echo 插件声明明确的 `text` 参数，便于小型工具模型生成合法参数。

## 已知边界

- GGUF 仍以 CPU 推理为主；1B-4B 模型在不同 Snapdragon、Dimensity 和 System WebView 版本上的性能、
  温升与长会话稳定性仍需扩大矩阵。
- PRoot 不是内核容器。获准执行的命令可修改共享 rootfs，第三方 Skill/插件仍应只授予完成任务所需的
  最小能力。
- 本地小模型能否稳定调用复杂工具取决于模型训练与量化；应用会限制可见工具并保留审批，但不能保证每个
  模型都能生成正确参数。
- Android 的“强制停止”会阻止 WorkManager 和后台服务，直到用户再次打开应用。

## 升级说明

使用与已安装版本相同签名的 `v0.0.12` APK 覆盖安装，才能保留会话、Provider、插件、模型和应用私有
文件。不要卸载旧版本后再安装，也不要使用不带 `-r` 的 `adb install`。

发布构建需通过 [AGENTS.md](../../AGENTS.md) 中的 Android 门禁、全量测试、Web 构建和签名 APK 校验。
