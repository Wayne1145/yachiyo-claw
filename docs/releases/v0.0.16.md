# Yachiyo Claw v0.0.16

`v0.0.16` 将 `v0.0.15` Debug 预发布中的新功能整理为可从正式签名版本覆盖升级的稳定预览版，并合入预发布标签之后的修复。

## Android 对话与界面

- 输入区改为紧凑的移动端布局，模型选择器、推理强度、附件入口和发送/录音/停止状态在窄屏下自适应收纳。
- 主页面加入带手势锁与状态保留的横向切换、共享标题栏、设置栈转场和液态玻璃层级。
- 自适应操作组会根据真实宽度降级为图标或溢出菜单；修复重复测量导致 React 最大更新深度崩溃的问题。
- Live2D 增加分阶段错误码、资源诊断、WebGL 上下文恢复、画质降档和后台页面资源暂停。

## 手机端 Vibe Coding V1

- 新增“开发”入口、项目创建向导、最近项目、目标能力说明和工作区状态。
- 支持 Web/PWA、Capacitor Debug APK 的手机本地构建与验证，Java/Kotlin APK 为 Beta；不支持的目标只准备源码，不伪造构建结果。
- 模型生成的写入先形成带 SHA-256 基线的 ChangeSet，按文件查看 Diff、应用或拒绝；冲突时停止覆盖。
- 构建任务、Git 变更、SAF 写回、APK 安装和应用启动均经过参数绑定审批；APK 在系统安装器前显示包名、版本、签名、权限和摘要。
- 构建任务由原生沙箱服务持久执行，应用进程重建后可恢复状态；PRoot 仍是兼容层而非内核安全边界。

## 本地模型加速

- 增加 `auto` 与 `extreme` 性能模式，实测初始化、首 token、prefill、decode 和驻留内存后缓存最快的成功配置。
- GGUF/llama.cpp 支持 Vulkan GPU 分层卸载、CPU 线程候选和 CPU 回退；运行状态展示实际后端、GPU 层数及回退原因。
- LiteRT-LM 探测 CPU/GPU 候选。NPU 仅在 ABI、SoC、专用模型声明、dispatch 和经许可厂商 Runtime 全部匹配时启用，公开包不承诺通用 NPU。
- 增加温控、内存余量、故障隔离、性能衰减重校准和模型变体选择。

## 下载、插件与更新

- 下载任务使用持久通知 ID，多个并发任务分别显示进度、速度和完成/失败状态；点击通知回到统一下载中心。
- 下载器在网络约束改变时重新调度活动任务，并继续执行来源、重定向、内网地址、大小和摘要校验。
- 插件中心支持保存自定义市场地址，页面预览不会提前启动 Worker；生命周期取消不会误记为插件故障。
- 插件、主题、本地模型和下载列表在窄屏下使用自适应操作组，危险操作仍保留独立确认。

## 正式发布审计修复

- 统一 `package.json`、Android `versionName` 和 `versionCode` 为 `0.0.16 / 16`。
- `pnpm check` 会先生成被忽略的 TanStack Router 路由表，修复全新克隆后 Vibe Coding 路由导致的类型检查失败。
- 移除误合入的请求数、Token、成本、操作数和总时长硬预算；用量继续记录，真正重复调用由三次重复/振荡检测器提示并停止。
- 移除不可移植的 Gradle daemon JVM/Foojay 配置，继续使用工作区固定的 Temurin 21。
- 修正第三方声明中 llama.cpp 上游提交号，并更新 CPU/Vulkan 能力边界。
- 修复 GGUF 首次冷启动时原生桥初始化阻塞进度探测、被误判为推理进程崩溃的问题；存活进程的短暂心跳延迟不再隔离唯一 CPU 后端，长期停滞仍会终止。
- 补齐英文模式下 Agent 开关、推理强度、聊天输入框、开发工作台和插件错误状态的本地化，避免主路径混用中英文。
- 无底栏入口的插件页改由设置栈承载，统一显示返回按钮和插件标题；修复插件标题重复、设置滚动内容穿透标题栏的问题。

## 验证范围与边界

- 发布门禁包含 TypeScript、Android foundation、原生日志隐私、全量 Vitest、Web 构建、Gradle 单元测试、Debug/Release APK 构建、签名连续性和 SHA-256 校验。
- 正式 APK 在 Android 12、`1200x2608` 模拟器上覆盖安装并进行关键页面与日志检查。
- Android 11、13、15/16 以及不同厂商 SoC 的性能和兼容性矩阵仍需扩大；NPU、Vulkan 和大型模型的可用性取决于设备、驱动、模型格式、量化和可用内存。
- `v0.0.15` 使用 Debug 签名，不能直接覆盖正式签名版本；请使用 `v0.0.16` 从 `v0.0.14` 或更早的同签名版本升级。
