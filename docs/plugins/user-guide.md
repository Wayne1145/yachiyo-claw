# 第三方插件使用说明

第三方插件可以增加 Agent 工具、设置入口、底部标签和由宿主渲染的声明式页面。插件不是普通主题或
Skill：脚本插件包含可执行 JavaScript，应只从可信来源安装。

## 安装来源

在 **设置 > 插件** 中可以从以下来源安装：

- 内置的已签名插件市场；
- 公开 HTTPS 插件 ZIP 地址；
- GitHub 仓库地址，其最新 Release 需要包含 `yachiyo-plugin.zip`；
- Android 系统文件选择器中的本地 ZIP。

Android 下载使用统一下载器。关闭页面或应用进程被系统回收后，下载会继续由 WorkManager 调度；包体
完成后会恢复到同一权限确认窗口。取消下载或删除下载记录不会在下次启动时偷偷重新创建安装任务。

安装前会显示插件 id、版本、作者声明、签名状态、可执行代码提示和每项能力的申请理由。取消授权不会
安装插件。市场验签表示包体由应用内置的受信任发布者密钥签署；HTTPS 或自签名不能替代作者验证。

## 能力说明

- `storage`：只访问该插件自己的加密键值空间。
- `ui`：提供由 Yachiyo Claw 验证并渲染的声明式页面，不能提交 HTML/CSS/DOM。
- `tools`：向 Agent 注册带插件命名空间的结构化工具。
- `network`：通过宿主代理访问清单中精确列出的公开 HTTPS 域名；每次重定向仍会检查。
- `sandbox`：在插件工作区执行 Linux 命令或读写文件。这是高风险能力，因为 PRoot 不是内核隔离，
  命令可以修改共享 Linux 环境并自行联网。
- `device`：读取或操作 Android 界面。安装时永远不会直接授予；只有官方市场验签插件可以在详情页
  单独申请，且仍要求全局手机控制、当前会话开关、Tool Broker 审批和一次性原生 nonce。

能力可以在插件详情页撤销，撤销会中断正在进行的对应调用。插件不能继承普通 Agent 在当前会话中的
授权，也不能读取 Provider 密钥、聊天、记忆、其他插件数据或宿主审计记录。

## 管理、更新和恢复

已安装插件可以停用并保留数据，或完全卸载。详情页显示能力状态、健康计数、最近错误、活动和特权操作
记录。重复故障会触发插件级熔断；重新启用需要用户操作，不会拖垮整个应用。

更新由用户确认后安装到不可变版本目录。权限扩大需要重新同意，`device` 在每次代码更新后都会撤销。
失败更新保留当前版本；最多保留三个已验证历史版本供显式回滚，回滚也不会恢复旧的特权授权。卸载会
停止 Worker 和原生任务、取消审批、撤销授权并删除插件代码、数据和工作区，同时保留宿主审计历史。

导航标签和设置入口只有在插件已启用、获得 `ui` 权限、满足 `minAppVersion` 且未被健康熔断时才显示。
看见插件已安装但没有入口时，应先检查这些状态。

## 运行边界

插件 JavaScript 在由 opaque-origin sandbox frame 创建的独立 Worker 中运行。它没有宿主 DOM、
Capacitor、localStorage、IndexedDB、Cache、直接 `fetch` 或任意原生桥；支持的行为只能通过纯数据 Host
API 请求。WebView 引擎漏洞、root 设备和获准的 Linux 命令仍属于残余风险。

开发插件、清单格式和 SDK 参见 [Plugin SDK](README.md) 与
[作者指南](../plugin-platform/authoring.md)，安全测试结论参见
[插件平台安全评审](../plugin-platform/security-review.md)。
